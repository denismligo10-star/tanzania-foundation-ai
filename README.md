# Tanzania Foundation AI

An ambitious AI research project originating from Tanzania.

## Vision
To develop a powerful general-purpose foundation model with strong African language capabilities and global relevance.

## Core Research Areas
- Foundation Models
- Transformer Architecture
- African Language Intelligence
- Natural Language Processing
- Machine Learning
- Reasoning and Evaluation
- AI Safety

- Git and GitHub

- Reproducible experiments
- Transparent evaluation
- Responsible AI development
